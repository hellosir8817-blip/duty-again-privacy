눈떠보니 듀티 개인정보처리방침

시행일: 2026년 11월 20일
개발자: Kwak MinKyu

Kwak MinKyu(이하 "개발자")는 「눈떠보니 듀티」(이하 "앱") 이용자의 개인정보와 데이터를 중요하게 생각하며, 앱에서 처리되는 정보와 그 이용 방법을 다음과 같이 안내합니다.

1. 앱에서 처리하는 정보

앱은 별도의 회원가입 또는 로그인을 요구하지 않습니다.

사용자는 앱에서 근무표, 근무형태, 업무명과 완료 여부, 근무시간, 개인 루틴 및 병동 루틴(Ward Pack), 호실/베드 정보, 추가 메모, 개인일정의 제목·날짜·시간·종일 여부·메모 등을 입력할 수 있습니다. 사용자가 직접 입력한 이러한 데이터는 기본적으로 기기 내부에 저장됩니다.

호실/베드와 추가 메모는 선택 입력 항목입니다. 앱은 환자의 성명, 주민등록번호 등 환자를 직접 식별할 수 있는 정보를 입력하도록 요구하지 않습니다. 사용자는 근무표 사진이나 업무·루틴·일정·공유 자료에 환자 식별정보 및 불필요한 민감정보를 포함하지 않도록 주의해야 합니다.

2. 근무표 사진 분석(BETA)

앱은 사용자가 선택적으로 이용할 수 있는 근무표 사진 분석 기능을 제공합니다. 사용자가 직접 사진을 선택하거나 촬영한 후 분석할 자신의 근무 행을 지정하면, 선택된 근무표 영역의 이미지 데이터가 근무코드 인식을 위해 개발자가 운영하는 분석 서버로 전송됩니다.

전송된 이미지 데이터는 Google의 Gemini API를 이용한 AI 분석을 위해 Google의 서비스로 전달될 수 있습니다.

개발자가 운영하는 분석 서버는 전송받은 근무표 이미지를 별도의 데이터베이스 또는 파일 저장소에 저장하도록 구현되어 있지 않으며, 분석 요청을 처리하고 결과를 앱에 반환하는 용도로 사용합니다.

Google 등 외부 서비스 제공자의 시스템에서 이루어지는 데이터 처리 및 제한적인 보관에는 해당 서비스 제공자의 정책과 이용 조건이 적용될 수 있습니다.

사진에 다른 직원의 정보 등이 포함될 수 있으므로 분석할 영역을 확인하고, 전송이 적절한 사진만 선택해 주시기 바랍니다. 사진 분석은 선택 기능이며, 이 기능을 이용하지 않고 근무 일정을 직접 입력할 수 있습니다. 인식된 근무는 사용자의 검토 및 확인 후 적용됩니다.

3. 개인일정 및 휴대폰 캘린더 연결

앱에서 직접 작성한 개인일정은 기기 내부의 앱 저장공간에 보관됩니다. 휴대폰 캘린더 연결 없이도 개인일정을 작성·조회·수정·삭제할 수 있습니다.

사용자가 휴대폰 일정 함께 보기를 직접 선택하고 Android 캘린더 접근 권한을 허용하면, 앱은 사용자가 선택한 휴대폰 캘린더의 일정 제목, 날짜·시간, 종일 여부 및 일정 표시를 위해 필요한 캘린더 정보를 읽어 Today와 근무표 화면에 표시할 수 있습니다.

외부 일정은 사용자가 보고 있는 날짜 또는 달에 필요한 범위에서 조회합니다. 앱은 읽어 온 휴대폰 캘린더 일정을 자체 개인일정 저장소에 복제하여 영구 저장하거나 개발자 서버로 전송하지 않습니다.

연결 및 함께 보기는 선택사항이며, 사용자가 이를 끄거나 연결을 해제하면 앱에서 외부 일정 표시가 중단됩니다. Android 기기 설정에서 캘린더 접근 권한을 철회할 수도 있습니다. 이러한 조작은 휴대폰 캘린더에 저장된 원본 일정이나 앱에서 직접 작성한 개인일정을 삭제하지 않습니다.

사용자가 '휴대폰 캘린더에 추가' 기능을 선택하면 Android의 외부 캘린더 앱으로 일정 작성 정보를 전달하여 해당 앱의 작성 화면을 열 수 있습니다. 실제 저장 여부는 사용자가 외부 앱에서 결정하며, 외부 캘린더 서비스의 저장·동기화·공유에는 해당 서비스 제공자의 정책이 적용됩니다. 앱은 외부 캘린더에 대한 직접 쓰기 권한(WRITE_CALENDAR)을 요청하지 않습니다.

4. 병동 루틴(Ward Pack) 및 자료 공유

사용자가 작성하거나 가져온 병동 기본 루틴, 근무형태별 업무 구성, 개인 설정 등은 앱 기능 제공을 위해 기기 내부에 저장됩니다.

사용자가 루틴 등의 공유·내보내기 기능을 직접 선택하면 업무명·메모 등 공유 자료에 포함된 내용이 선택한 공유 대상 또는 앱에 전달될 수 있습니다. 공유된 자료의 보관과 이후 처리에는 사용자가 선택한 수신자 또는 외부 앱의 정책이 적용될 수 있으므로, 공유 전에 내용을 확인해 주시기 바랍니다. 개발자는 일반 루틴 데이터를 자체 서버에 자동 업로드하지 않습니다.

5. 정보 이용 목적 및 외부 서비스

앱에서 처리되는 정보는 근무 일정 관리, 개인일정 및 휴대폰 일정 함께 보기, 개인 업무·병동 루틴 관리, 알림 제공, 사용자가 요청한 자료 공유 및 근무표 사진 분석 기능을 제공하기 위해 이용됩니다.

근무표 사진 분석 기능에는 Google Cloud 및 Google Gemini API가 사용됩니다. 일반적인 근무 일정·업무·루틴·자체 개인일정 데이터와 휴대폰에서 읽은 외부 일정은 근무표 사진 분석을 위한 데이터로 전송하지 않습니다. 분석 서버로 전송되는 것은 사용자가 해당 기능에서 선택한 근무표 이미지 영역입니다.

개발자는 맞춤형 광고 제공 또는 광고 프로파일 작성을 목적으로 사용자의 업무 데이터나 근무표 이미지를 이용하지 않습니다.

6. 데이터 보관 및 삭제

앱에서 직접 입력한 데이터는 별도의 계정 없이 기기 내부에 보관됩니다. 사용자는 앱에서 제공하는 해당 항목의 삭제 기능을 이용할 수 있으며, 기기의 앱 데이터 삭제 또는 앱 삭제를 통해 앱 내부 저장 데이터를 삭제할 수 있습니다. 기기 운영체제나 사용자가 설정한 백업에 별도의 복사본이 있는 경우에는 해당 백업의 관리 방식이 적용될 수 있습니다.

외부 캘린더 연결 해제는 외부 일정의 앱 내 표시를 중단하는 것이며, 휴대폰 또는 외부 캘린더 제공자에 저장된 원본 일정을 삭제하지 않습니다. 외부 캘린더 원본 일정은 해당 캘린더 앱 또는 서비스에서 관리·삭제해야 합니다.

개발자가 운영하는 근무표 분석 서버는 분석을 위해 전달받은 이미지를 별도의 데이터베이스 또는 파일 저장소에 영구 보관하도록 구현되어 있지 않습니다. 외부 서비스 제공자의 시스템에서 이루어지는 보관 또는 로그 처리는 해당 서비스 제공자의 정책 및 이용 조건에 따를 수 있습니다.

7. 데이터 보호 및 접근 권한

근무표 사진 분석을 위한 앱과 분석 서버 간 통신에는 HTTPS 암호화 통신을 사용합니다. 개발자는 서비스 제공에 필요한 범위로 데이터 처리를 최소화하기 위해 노력합니다.

휴대폰 캘린더 읽기 권한(READ_CALENDAR)은 사용자가 외부 일정 함께 보기 기능을 선택할 때 요청하며, 외부 일정 조회에 사용합니다. 사진 선택·촬영 및 알림 관련 접근은 사용자가 해당 기능을 이용할 때 기기에서 허용한 범위 내에서 처리합니다.

8. 이용자의 선택

근무표 사진 분석 및 휴대폰 캘린더 연결은 선택 기능입니다. 사용자는 사진 분석 없이 근무를 직접 입력하고, 외부 캘린더 연결 없이 앱 자체 개인일정을 이용할 수 있습니다.

휴대폰 일정 함께 보기는 앱 설정에서 중단할 수 있고, 캘린더 접근 권한은 Android 기기 설정에서 철회할 수 있습니다. 외부 앱으로 일정이나 루틴을 보내는 경우에도 사용자가 해당 기능을 직접 선택합니다.

9. 아동의 개인정보

본 앱은 의료기관 종사자의 업무 보조를 목적으로 하며, 아동을 대상으로 개인정보를 수집하기 위해 설계된 서비스가 아닙니다.

10. 개인정보처리방침의 변경

앱의 기능 또는 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침이 변경될 수 있습니다. 중요한 변경사항이 있는 경우 앱 또는 개인정보처리방침 게시 페이지를 통해 안내합니다.
