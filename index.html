눈떠보니 듀티 개인정보처리방침

시행일: 2026년 10월 1일
개발자: Kwak MinKyu

Kwak MinKyu(이하 "개발자")는 「눈떠보니 듀티」(이하 "앱") 이용자의 개인정보와 데이터를 중요하게 생각하며, 앱에서 처리되는 정보와 그 이용 방법을 다음과 같이 안내합니다.

1. 앱에서 처리하는 정보

앱은 별도의 회원가입 또는 로그인을 요구하지 않습니다.

사용자는 앱에서 근무표, 근무형태, 업무명, 업무 완료 여부, 근무시간, 루틴, 호실/베드 정보 및 추가 메모 등을 입력할 수 있습니다. 이러한 일반 업무 데이터는 기본적으로 사용자의 기기 내부에 저장됩니다.

호실/베드 및 추가 메모는 선택 입력 항목입니다. 앱은 환자의 성명, 주민등록번호 등 환자를 직접 식별할 수 있는 정보를 입력하도록 요구하지 않습니다. 사용자는 업무 기록에 환자의 직접 식별정보 또는 불필요한 민감정보를 입력하지 않도록 주의해야 합니다.

2. 근무표 사진 분석(BETA)

앱은 사용자가 선택적으로 이용할 수 있는 근무표 사진 분석 기능을 제공합니다.

사용자가 직접 사진을 선택하거나 촬영한 후 분석할 자신의 근무 행을 지정하면, 선택된 근무표 영역의 이미지 데이터가 근무코드를 인식하기 위한 목적으로 개발자가 운영하는 분석 서버로 전송됩니다.

전송된 이미지 데이터는 Google의 Gemini API를 이용한 AI 분석을 위해 Google의 서비스로 전달될 수 있습니다.

개발자가 운영하는 분석 서버는 전송받은 근무표 이미지를 별도의 데이터베이스 또는 파일 저장소에 저장하도록 구현되어 있지 않으며, AI 분석 요청을 처리하고 분석 결과를 앱에 반환하는 용도로 사용합니다.

Google 등 외부 서비스 제공자의 시스템에서 이루어지는 데이터 처리 및 제한적인 보관에는 해당 서비스 제공자의 정책과 이용 조건이 적용될 수 있습니다.

근무표 사진 분석 기능은 선택 기능이며, 사용자는 해당 기능을 이용하지 않고 근무 일정을 직접 입력할 수 있습니다.

3. 정보의 이용 목적

앱에서 처리되는 정보는 근무 일정 관리, 개인 업무 및 루틴 관리, 알림 제공, 근무표 사진 분석 등 사용자가 요청한 앱 기능을 제공하기 위한 목적으로 이용됩니다.

개발자는 맞춤형 광고 제공 또는 광고 프로파일 작성을 목적으로 사용자의 업무 데이터나 근무표 이미지를 이용하지 않습니다.

4. 외부 서비스 및 데이터 처리

근무표 사진 분석 기능에는 Google Cloud 및 Google Gemini API가 사용됩니다. 해당 서비스는 근무표 이미지 분석 기능을 제공하기 위한 외부 서비스로 사용됩니다.

앱의 일반적인 근무 일정, 개인 업무, 루틴, 호실/베드 및 메모 데이터는 사용자가 근무표 사진 분석 기능을 통해 전송하는 선택된 이미지 영역을 제외하고 해당 AI 분석을 위해 외부 서버로 전송되지 않습니다.

5. 데이터 보관 및 삭제

기기 내부에 저장되는 앱 데이터는 사용자의 기기에 보관됩니다. 사용자는 앱에서 제공되는 삭제 기능 또는 기기의 앱 데이터 삭제, 앱 삭제 등의 방법을 통해 해당 데이터를 삭제할 수 있습니다.

개발자가 운영하는 근무표 분석 서버는 분석을 위해 전달받은 이미지 데이터를 별도의 데이터베이스 또는 파일 저장소에 영구 보관하도록 구현되어 있지 않습니다.

외부 서비스 제공자의 시스템에서 이루어지는 제한적인 보관 또는 로그 처리는 해당 서비스 제공자의 정책 및 이용 조건에 따를 수 있습니다.

6. 데이터 보호

근무표 사진 분석을 위한 앱과 분석 서버 간 통신에는 HTTPS 암호화 통신을 사용합니다. 개발자는 서비스 제공에 필요한 범위로 데이터 처리를 최소화하기 위해 노력합니다.

7. 이용자의 선택

근무표 사진 분석은 선택 기능입니다. 사용자는 사진 분석 기능을 이용하지 않고 근무 일정을 직접 입력할 수 있습니다.

사진 또는 카메라 접근이 필요한 기능은 사용자가 해당 기능을 선택하여 사용하는 경우에만 이용됩니다.

8. 아동의 개인정보

본 앱은 의료기관 종사자의 업무 보조를 목적으로 하며, 아동을 대상으로 개인정보를 수집하기 위해 설계된 서비스가 아닙니다.

9. 개인정보처리방침의 변경

앱의 기능 또는 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침이 변경될 수 있습니다. 중요한 변경사항이 있는 경우 앱 또는 개인정보처리방침 게시 페이지를 통해 안내합니다.
